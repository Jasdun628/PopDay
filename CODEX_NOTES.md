# Codex Notes

## UI Date Formats

Build/version timestamps should be short and include time of day:

```text
13:28 Thurs 28th Dec 2026
```

Use 24-hour time with a colon, short weekday, ordinal day, short month, and full year.

## Session Summary Screens

When building or editing session-summary screens, include a clear pre-session inputs section.

Prioritise:

- distance to target
- calculated spot size
- target/location
- selected mode
- device
- baseline or offsets used

Distance to target and calculated spot size should be prominent near the top because they explain the measurement geometry.
